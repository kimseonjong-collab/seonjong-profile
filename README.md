# Seon Jong Kim — Executive Profile

김선종 Executive Profile 정적 웹사이트입니다.

## 구성
- index.html — 모바일/PC 반응형 프로필
- profile.jpg — 프로필 사진 (Hero 영역에서 배경 Blur 포함)

## 배포
Vercel에서 이 저장소를 Import하면 별도 Build Command 없이 정적 사이트로 배포할 수 있습니다.

- Framework Preset: Other
- Build Command: 비움
- Output Directory: 비움
- Root Directory: ./

## 사진
저장소 루트에 파일명을 정확히 `profile.jpg`로 업로드하면 Hero 사진과 Blur 배경에 동시에 적용됩니다.
